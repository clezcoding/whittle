# clezcoding/homebrew-tap

Homebrew tap for [Whittle](https://github.com/clezcoding/whittle), a Swiss army knife for your Mac.

```sh
brew tap clezcoding/tap

brew install --cask clezcoding/tap/whittle     # the desktop app
brew install --formula clezcoding/tap/whittle  # the command line only
```

The formula and the cask in this repository are generated by the release workflow of the main
repository. **Do not edit them by hand**; change the templates in
[`packaging/homebrew`](https://github.com/clezcoding/whittle/tree/main/packaging/homebrew) instead.

`brew uninstall --zap --cask whittle` also removes `~/.config/whittle`. Items in quarantine
(`~/.whittle`) are left alone on purpose; use `whittle purge` first if you want them gone.
