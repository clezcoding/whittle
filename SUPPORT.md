# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/clezcoding/whittle/discussions)
- **A bug:** [open an issue](https://github.com/clezcoding/whittle/issues/new/choose) and include `whittle --version` and, if relevant, the output of `whittle apps`
- **A wrong or missing rule:** use the *Rule* issue form
- **A security problem:** see [SECURITY.md](SECURITY.md), not a public issue

Before filing, a look at the [README FAQ](README.md#faq) and the [roadmap](docs/ROADMAP.md) may already answer it.
